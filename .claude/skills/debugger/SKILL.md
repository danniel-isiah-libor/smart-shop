---
name: debugger
description: Debug code and explain errors. Use when asked to debug or explain code.
argument-hint: [file] [line]
---

1. Read and analyze error logs from laravel logs.
2. If the error is in a specific file and line, read that file and line to understand the context.
3. Identify the root cause without executing any code.
4. Suggest a fix or explain the error in simple terms.
5. Once fix is applied, run the test and prove the bug is fixed. If the bug persists, repeat the process until resolved.
